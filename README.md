# Quantifying plasmid relatedness from short-read data

Short-read assembly rarely reconstructs a plasmid as a single contig — it
fragments it into pieces whose true order and orientation are unknown.
This project measures how much that fragmentation actually degrades
rearrangement-distance estimates between two plasmids, by sampling many
possible fragment orderings for a pair and looking at the resulting
distribution of distances (instead of trusting a single distance computed
on an arbitrary assembler-chosen order).

## Core pipeline

- **`generateShortRead.py`** — the core unit of work. Given two
  already-fragmented plasmid FASTA files, it reconstructs both plasmids
  under many different fragment orderings and computes the rearrangement
  distance for each ordering, producing a distance *distribution* for that
  one plasmid pair. Two distance backends are selectable via its
  `implementation` flag:
  - **pling** (external tool, invoked via subprocess) — containment + DCJ
    distance.
  - **`break_distance.py`** — this project's own nucmer-alignment-driven
    synteny-block + 2-break distance implementation.

- **`groupCall.py`** — batch orchestrator. Reads a list of plasmid pairs
  (from one of several result/ground-truth files produced at different
  points in the project) and fans out parallel `generateShortRead.py`
  subprocess calls over them. Almost every experiment in this project was
  launched through one of its `func=0..8` branches — see the module
  docstring and the `__main__` dispatch table at the bottom of the file for
  what each one does.

- **`run_pling.py`** — baseline comparison: runs pling once (repeated 5x to
  check pling's own run-to-run variability) on a *fixed* fragment order,
  with no sampling, so the sampled-distribution results can be compared
  against a "naive" single-order baseline.

## Building the datasets

- **`syntethic.py`** — generates the synthetic ground-truth dataset. Takes
  a real plasmid, applies a random number of rearrangement events
  (reversal / transposition / insertion / deletion) to it, and records the
  *exact* 2-break distance between original and rearranged genome. This is
  what gives some experiments a known correct answer to validate
  pling/break_distance.py against, rather than only comparing them to each
  other.

- **`bin_fragments.py`** — for the real short-read dataset: aligns each
  sample's assembled contigs (nucmer) against that sample's reference
  plasmids and assigns ("bins") each contig to whichever reference(s) it
  covers well (>85%), building the `binned_fragments/` dataset from
  `fragmentedDatabase/` + `plasmid_references/`.

## Plotting / analysis

- **`plotting.py`** — paginated violin plots of a distance distribution
  file (variance per pair).
- **`plot_vs_ground_trhuth.py`** — compares binned real-short-read distance
  distributions against ground-truth distances computed from full-length
  reference sequences; reports match/over/under-estimate rates and plots
  scatter + per-pair violins for the mismatches.
- **`variance_vs.py`** — a stack of six variance-vs-property analyses
  (contig count, plasmid length, length difference, mash distance, error
  vs. those same properties, plus a standalone pling-vs-mash scatter). Only
  one variant is active at a time (see the file's module docstring) — the
  rest are commented out and swapped in by hand as needed.
- **`annotate.py`** — early exploratory code; kept for reference but not
  currently runnable as-is (see its module docstring for why).

## Data sources

These directories aren't tracked in this repo (too large / mostly
regeneratable) but are what the scripts above read from and write to:

| Directory | Contents |
|---|---|
| `fastas/` | Original full-length plasmid assemblies from the pling GitHub repo. Artificially fragmented for testing, since short-read assembly can't yield full-length plasmids on its own. |
| `syntethic/regenerated/` | Synthetic plasmids generated by `syntethic.py` from `fastas/`, each with a known ground-truth rearrangement distance from its original. |
| `plasmid_references/` | Reference (full-length) plasmid sequences for a real short-read dataset from another paper, used as an independent real-data test case. |
| `fragmentedDatabase/` / `fragmented_database_final/` | Short-read assemblies (contigs) for that real dataset, before binning. |
| `binned_fragments/` | Contigs from `fragmentedDatabase/`, assigned to their best-matching `plasmid_references/` sequence by `bin_fragments.py`. |

## External dependencies

- `pling` CLI — one of the two distance backends.
- MUMmer (`nucmer`, `delta-filter`, `show-coords`) — alignment backbone for
  both `break_distance.py` and `bin_fragments.py`.
- `cd-hit-est` — synteny-block clustering in `break_distance.py`.
- `mash` — used to produce the mash-distance comparison files consumed by
  some of the plotting scripts.
- Python: `matplotlib`, `numpy`, `pandas`, `scipy`.

## Known rough edges

Documented in more detail in the relevant docstrings, flagged here so
they're not mistaken for intended behavior when reading the code:

- `annotate.py`'s plotting functions depend on module-level `distances`/
  `comparisons`/`colors` variables that are only ever set up in commented-out
